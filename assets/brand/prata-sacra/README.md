# Talentum — direção prata sacra

A medalha usa uma cruz latina dentro de um arco inspirado em vitrais e doze linhas gravadas no aro. O símbolo permanece legível sem inscrições pequenas no ícone do aplicativo.

| Papel | Cor |
|---|---|
| Prata clara | `#F8F9F8` |
| Prata base | `#D9E0E2` |
| Prata de contorno | `#82939C` |
| Azul da gravação | `#244156` |
| Azul do nome e texto | `#1B2D39` |
| Fundo marfim | `#F7F4ED` |

Os SVGs são vetoriais e têm fundo transparente. Os PNGs servem para visualização e uso em superfícies que não aceitam SVG.
